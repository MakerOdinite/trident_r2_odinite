# trident_r2_odinite
Trident LDO 300 cube mod build  


## what this is....
1) Years ago I bought a LDO Voron Trident 300 cube kit from Fabreeko.
2) Life happened and it sat in storage for a bit. (3 and a half years is a bit, right)
3) Figured it was time to build it, and mod it before i build "do it nice, not twice"
4) I want a stable printer for ABS, ASA, and multimaterial printer
5) Decided to go all in on an INDX system
6) Hence this repo was born as a place for me to virtually build it before I really build it!
7) This repo will also serve as a record of the build process

## other mods changes
These were driven by what I had available / what I was able to source to support stable ABS/ASA design goal)

rail backers
change AB motors with longer shafts (OMC 17HS19-2504S-H-V6)
AB stepper coolers
AB beefier drivers BTT TMC5160 Pro
dual 120mm underbed chamber circulators
Stealthmax V2 (intake at top, recirculate on bottom)
Bondtech INDX with 7 tools
rsp-24-320 psu
manta mp8 v2
pi cm5
cm5 copper heatspreader
4011 heatink on heatspread
custom fan cooling on cm5
5015 cooling for stepper drivers
delta fans
btt hdmi5 screen
chamber LEDs
Change Z axis trap nuts to PEEK
rock and roller for bottom access
